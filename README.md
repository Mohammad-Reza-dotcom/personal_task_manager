# Personal Task Manager

## Description

Personal Task Manager is a simple command-line application built with Python.

## Features

- Add new tasks.
- Set task priorities.
- View all tasks.
- Complete tasks.
- Delete tasks.
- Save tasks in JSON format.
- Admin Mode with password protection.

## Installation

1. Clone the repository:

   git clone https://github.com/amirali-sh88/personal_task_manager.git

2. Open the project folder:

   cd personal_task_manager

3. Install dependencies:

   pip install -r requirements.txt

## Usage

Run the application:

    python main.py
